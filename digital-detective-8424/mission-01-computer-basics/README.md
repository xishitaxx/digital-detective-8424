### Task 1.1: Trace one activity using IPOS
| Stage | What happens in your example? | Possible hardware / component |
| :--- | :--- | :--- |
| **Input** | You type characters on the physical keyboard. | Keyboard |
| **Processing** | The CPU interprets keystrokes and temporary RAM holds data. | CPU and memory |
| **Output** | The letters appear visually on your display screen. | Screen |
| **Storage** | Saving writes the data permanently to your disk drive. | SSD|

### Task 1.2: Identify hardware and software
| Item / software name | Hardware or software? | Software type (if applicable) | Purpose |
| :--- | :--- | :--- | :--- |
| **Keyboard** | Hardware | Not applicable | Used to enter text |
| **macOS / Windows** | Software | Operating System | Manages the computer and its resources |
| **VS Code** | Software | Application software | Helps users perform tasks such as writing code |
| **Antivirus Utility** | Software | Utility software | Helps maintain, protect or manage the computer |
