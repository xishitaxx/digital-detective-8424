## 4. My understanding
A compiler translates source code into another form such as machine code before the program runs, often producing a standalone executable that runs quickly once built. An interpreter reads and executes instructions at runtime instead of compiling the whole program ahead of time into a separate binary, which helps during testing and debugging, though real language implementations can combine both approaches. Running hello.py with python3 showed how high-level source code can be executed directly from the command line.

### Compiler vs. Interpreter Comparison
| Point | Compiler | Interpreter |
| :--- | :--- | :--- |
| **When translation / execution happens** | Translates source code into another form (often machine code) before the program runs | Executes code by reading and carrying out instructions at runtime |
| **Typical output** | Compiled target/machine code or an executable artifact | Direct runtime execution (rather than a standalone pre-compiled executable) |
| **One example** | C / C++ | Python / JavaScript |
| **One advantage** | Fast execution once compiled ahead of time | Convenient interactive execution and easier step-by-step debugging |
